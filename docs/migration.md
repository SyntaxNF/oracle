## 相对已取消审查版的收敛

- INDEX 的 UNIQUE/BITMAP 与 LOCAL/GLOBAL_RANGE/GLOBAL_HASH 组合 CASE 合并为 TABLE 的选项和 `index_partition_clause`，保留 CLUSTER、BITMAP_JOIN、DOMAIN
- TRIGGER 合并为 SIMPLE_DML、INSTEAD_OF_DML、COMPOUND_DML、COMPOUND_NONEDITIONING_VIEW、SYSTEM；body/CALL、edition 和 ordering 使用共享节点
- 临时表复用列、约束与 LOB 节点；不再使用临时表专用叶子目录表达兼容限制
- `storage_option` / `physical_attribute` / `index_attribute` / `profile_option` / `sequence_option` 等重复属性袋变为复数的固定顺序节点；真正的成员列表仍重复
- 声明、程序语句和异常处理节点现在接受完整自由片段，详见 [输入与生成边界](semantic-contracts.md)。片段自带分号；不要与外层 END 的分号混淆

## 标点与输入

- 带引号的重复值增加 `quoted_*` 包装节点；内部叶子的转义规则不变，外围引号由模板输出
- 列表分区元组、ARRAY DML 元组与 PIVOT ANY 增加完整成员节点；不要再把重复次数挂在字面右括号或裸关键字上
- 对象类型的 attribute_member/method_member、多分区 SPLIT 的 range_partition_member/list_partition_member 负责尾逗号；保持零次可展开，圆括号最终尾逗号由生成约定清理
- Directory 路径使用模板单引号；CALL host/indicator 变量使用模板冒号，传入值不要重复包含外围标点
- `query_statement` 仍复用 SELECT；`FORCE` 不写死 FALSE，省略时沿用 Oracle 默认值
- 没有改变执行权限、对象锁定或安全策略；本文不要求实现完整 Oracle 上下文验证器
